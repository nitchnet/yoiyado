宵宿（YOIYADO）プライバシーポリシー

宵宿は、作成者本人がひとりで使うためのホテル予約管理ツールです。一般には公開・提供していません。

扱う情報

  • 作成者本人の Gmail にある、ホテルの予約確認・キャンセル・会員資格・キャンペーンのメール（読み取りのみ）
  • 作成者本人の Google カレンダーの宿泊予定（読み取りのみ）

使い方

  • 予約の一覧、料金の比較、会員資格の進捗を作成者本人に表示するためだけに使います。
  • メールの送信・削除・変更、カレンダーの書き込みはしません。
  • 第三者への提供・販売・広告への利用はしません。

保管

読み取った情報は、作成者本人のパソコンと本人の Google アカウント内（Apps Script・スプレッドシート）にだけ保管します。

Google API の利用について

Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
